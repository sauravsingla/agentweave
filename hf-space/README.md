# AgentWeave — Route Before You Reason

Interactive browser-only demonstration of AgentWeave's core idea: **scope and reduce a large tool catalog before model inference**.

The demo is intentionally self-contained and runs entirely in the browser. It does **not** execute external tools or call an LLM; it visualizes deterministic scope filtering and task-aware tool narrowing so visitors can understand the pre-inference routing boundary immediately.

- Live Space: https://huggingface.co/spaces/sauravsingla08/AgentWeave
- Source: https://github.com/sauravsingla/agentweave
- Dataset: https://huggingface.co/datasets/sauravsingla08/AgentWeave-Tool-Routing
- Paper: https://arxiv.org/abs/2608.23078
