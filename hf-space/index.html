Scope before routing

Role, tenant, permission, risk, and policy constraints can remove tools before task-aware selection. In this demo, write tools are excluded unless explicitly permitted.

2
Reduce model-visible tools

The router scores only the permitted remainder and exposes a bounded top-k set, reducing the action space the model must reason over.

3
Validate before execution

Routing does not grant execution permission. The full AgentWeave runtime adds schema validation, authorization, replay/idempotency protection, execution, recovery, and telemetry.
