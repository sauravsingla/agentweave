# AgentWeave Paper

## AgentWeave: Routing Before Reasoning for Efficient Function Calling in Tool-Rich Language Models

**Authors:** Saurav Singla, Aarav Singla, Advik Gupta, Parnika Gupta  
**arXiv:** 2608.23078  
**Paper:** https://arxiv.org/abs/2608.23078

AgentWeave studies deterministic pre-inference routing for tool-rich language-model agents. The paper evaluates whether reducing the model-visible candidate action space before inference can improve function-calling reliability while leaving the downstream model unchanged.

### Research boundary

The paper reports a frozen BFCL-derived routing-pressure study. It is not an official full BFCL leaderboard submission. The repository keeps frozen evaluation evidence separate from later framework and experimental extensions.
